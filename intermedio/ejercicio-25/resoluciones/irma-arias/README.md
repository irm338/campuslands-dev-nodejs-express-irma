# Ejercicio 25: Testing de rutas

## Propósito

Verificar el comportamiento HTTP de una ruta RPG con `node:test` y `fetch`. La prueba confirma el código `200` y el formato JSON entregado por el endpoint.

## Ejecución

Requiere Node.js 20 o superior. Ejecuta `npm install` y después `npm test`. Para iniciar el servidor de forma manual, ejecuta `npm run dev`.

## Endpoint probado

`GET /api/heroes` devuelve la lista de héroes disponibles.
